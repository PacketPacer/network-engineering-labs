# Network Engineering Labs

This repository contains hands-on network engineering labs focused on building and troubleshooting enterprise-style networks.

## Goals
- Strengthen network engineering fundamentals
- Gain hands-on experience with routing, switching, and network services
- Document learning through real lab scenarios

## Lab Topics (in progress)
- VLANs and Inter-VLAN Routing
- Static and Dynamic Routing
- DHCP and DNS
- Network Troubleshooting

## Tools
Cisco Packet Tracer
Wireshark
Linux

## Notes
Labs are added progressively and include topology diagrams, configurations, and troubleshooting steps
